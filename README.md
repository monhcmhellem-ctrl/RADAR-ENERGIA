# ⚡ RADAR ENERGIA
### Análise de Dados Operacionais do Setor de Energia

Projeto de portfólio voltado à análise de dados operacionais do setor elétrico, utilizando Python, Pandas, SQL e Power BI para transformar dados em indicadores que apoiam o acompanhamento de desempenho, a identificação de desvios e a tomada de decisão.

> **Objetivo:** demonstrar habilidades em análise de dados, qualidade da informação, indicadores operacionais e melhoria contínua aplicadas ao setor de energia.

## 🎯 Objetivos do projeto

- Explorar e validar bases de dados operacionais.
- Identificar dados ausentes e possíveis inconsistências.
- Analisar ordens de serviço e seus respectivos status.
- Acompanhar indicadores de conclusão e backlog operacional.
- Comparar resultados entre regionais.
- Avaliar indicadores relacionados ao cumprimento de SLA.
- Analisar reincidências de ocorrências.
- Consolidar indicadores para apoiar a gestão operacional.

## 🛠️ Tecnologias utilizadas

- **Python:** processamento e análise de dados.
- **Pandas:** manipulação, validação e consolidação de bases.
- **SQL:** consultas e análise estruturada de dados.
- **Power BI:** visualização de indicadores e construção de dashboards.
- **Git e GitHub:** versionamento e documentação do projeto.

## 📈 Análises desenvolvidas

2. Validação da qualidade dos dados.

## 💡 Aplicação para o negócio

O projeto demonstra como dados operacionais podem ser utilizados para acompanhar o desempenho das equipes, identificar gargalos, monitorar pendências e apoiar ações de melhoria contínua.

## 📌 Sobre os dados

**Este é um projeto demonstrativo de portfólio.** As bases utilizadas são fictícias e foram criadas para fins de estudo e demonstração técnica. Não representam dados oficiais da Equatorial, de distribuidoras de energia ou da ANEEL.
